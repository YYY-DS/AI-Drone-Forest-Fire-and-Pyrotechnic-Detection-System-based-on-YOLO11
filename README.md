# AI无人机森林防火烟火检测系统（基于YOLO11）
基于YOLO11深度学习与无人机视觉的森林烟火实时检测方案，用于火情早期预警、大范围巡检与灾后监测。

## 项目简介
本系统以**YOLO11**为核心检测算法，搭配无人机、高清摄像、无线传输与地面指挥终端，实现森林区域烟火自动识别、定位与告警，助力火情早发现、快处置，降低灾害损失。

## 核心技术
- 检测算法：YOLO11，小目标检出强、推理快、复杂环境鲁棒性好。
- 视觉采集：无人机高清可见光成像，覆盖广、可达性强。
- 处理流程：航拍采集→图像预处理→YOLO11烟火检测→实时定位上报告警。

## 系统优势
- 预警及时：火情初期快速识别，大幅压缩响应时间。
- 覆盖全面：无人机灵活巡检，覆盖偏远与人工难达区域。
- 识别精准：降低误报漏报，适配多变光照与天气。
- 成本可控：相比人工巡护与固定站点，部署运维更经济。

## 应用场景
- 森林火情早期预警
- 高火险区常态化监控
- 火灾后态势评估与余火监测

## 未来规划
- 融合红外/热成像等多模态数据，提升复杂环境适应性
- 多机协同组网，扩大覆盖与监测密度
- 持续迭代算法，进一步提升精度与速度
